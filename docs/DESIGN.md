# Software Design

- `GPIO.c`: GPIO abstraction
- `TIMER.c`: time and delay functions
- `TWAI.c`: CAN/TWAI driver
- `DISPLAY.c`: 4-digit multiplexed display
- `RELAY.c`: relay and safety-output driver
- `LOAD_CELL.c`: filtering, calibration and weight calculation
- `NVS.c`: persistent configuration storage
- `WIFI.c`: access-point management
- `DNS.c`: captive DNS responder
- `WEB_SERVER.c`: HTTP interface
- `SYSTEM.c`: application state and safety logic
- `main.c`: initialization and FreeRTOS tasks
